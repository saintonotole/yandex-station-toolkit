Порядок действий

  1. Скачайте прошивку вашей модели — ниже.
  2. Запустите сервер и впишите в роутере DNS = IP этого компьютера — из подсети, где будет колонка.
  3. Сбросьте колонку: пауза (▶/⏸) 7–10 с до жёлто-салатового индикатора.
  4. Добавьте её в «Дом с Алисой» и дойдите до ввода пароля Wi-Fi.
  5. Ровно на экране пароля Wi-Fi включите «Подмена» — раньше не включать. В журнале появится adbd.
  6. DNS роутера — в конце: сначала закрепите root в «Доступ» (OTA выкл, SSH вкл), иначе обновление его закроет.
