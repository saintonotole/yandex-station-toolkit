# Yandex Station ToolKit

Приложение (Windows x64/ARM64, Linux amd64/arm64, macOS universal) для управления Яндекс Станциями в локальной сети:
находит колонки, автоматически (насколько это возможно) проводит джейлбрейк, закрепляет результат
(автозапуск ADB, SSH, блокировка OTA).

## Возможности

- **Джейлбрейк колонки**: локальный DNS-сервер (прозрачный режим и
  режим подмены) отдаёт колонке уязвимую прошивку и включает ADB; дальше
  приложение само включает автозапуск ADB, поднимает SSH, блокирует OTA и перезагружает колонку.
- **Поиск колонок** в локальной сети, опознание модели.
- **SSH**: по ключам или без авторизации.
- **Обзор**: виджеты ресурсов (температура, память, Wi-Fi, диск, аптайм).
- **Консоль**: интерактивный терминал на колонке.
- **Пакеты**: yse (Entware + .yap, качается с GitHub при установке),
  YAM 0.2 (на самой колонке), BetterYAM (Мини, Лайт, Мини 3).

## Требования

- Колонки в той же локальной сети.
- Запуск DNS- и веб-сервера: свободные порты 53, 80 и 443; права администратора,
  если система их запрашивает.

## Сборка

```sh
scripts/build.sh   # gofmt + vet + test + сборка в dist/
```

Нужен Go (версия в `go.mod`); Windows-сборка кросс-платформенная без CGO.
